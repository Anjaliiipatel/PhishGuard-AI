# CyberGuard AI
Developed a fully interactive web application that helps users detect, assess, and respond to common cybersecurity threats such as phishing emails, malicious links, account takeovers, scareware pop-ups, and potential malware infections.

The application features:

Scenario-based decision flow: Users select the type of threat, answer guided questions, and receive tailored recovery steps based on their responses.

Guided mode navigation: Step-by-step instructions with “Next,” “Back,” and “Done” controls for real-time incident response assistance.

Dynamic UI: Built with a dark-themed modern interface and responsive layout to ensure accessibility and user engagement across devices.

Quick action buttons: Speeds up reporting and recovery by offering common, context-aware choices for each question.

Personalized recommendations: Generates recovery plans that adapt to user-provided details, including extra security notes and follow-up actions.

Technologies Used:

Frontend: React (Vite), JSX, CSS3

UI Components & Styling: Custom CSS, Lucide React icons, responsive layouts

Interactivity: React hooks (useState, useEffect, useRef) for state management and chat-style conversation flow

Skills: JavaScript, Python, +5 skills
